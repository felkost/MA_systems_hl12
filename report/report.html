Usage scenario

One question, one trace, four evaluator scores.

StepWhat happensVisible in Langfuse
1You ask a question—
2-4Plan → Research → Critique (revisions capped)Trace tree grows
5You approve, edit, or reject the report—
6Report saved, trace completeTracing tab: full tree, session, user
7Evaluators score the trace, ~1-2 min laterScores tab: 4 scores

Limitations

  • Every cost above is one measurement, not an average.
  • Judge models are not validated against human labels.
  • citation-groundedness checks the report's own citations, not the actual retrieved text.
  • Research/critique alternation has no hard limit — one run cost $0.31 with no critic involved at all.
  • A Windows console encoding bug can crash the REPL on certain web-search text (known, not fixed).
